方法说明

  • 风险指标按「当前持仓回放」：假设现在的持仓在过去 500 个交易日（自 2024-11-14 起）不变，用各标的日收益率折算人民币后计算组合收益率。
  • VaR 历史法取经验分位数；参数法假设正态分布；CVaR 为超过 VaR 部分的平均损失。现金日收益按 0 计。
  • 所有数字由代码计算（facts.json 可复核）；大模型只写解读，输出经过数字溯源校验，不提供任何投资建议。
