# Cyron Veritas 资管中台设计（股票多头 · 量化 · PE/VC）

目标：做成一家小型私募真实在用的「投研 + 运营 + 风控 + 报告」中台，而不是单次运行的演示。
三类产品共用一条骨架：**产品与合同 → 每日账务（估值表）→ 净值 → 风控与合规 → 业绩与归因 → 报告**，区别只在策略和账务科目。

## 1. 产品

| 产品 | 类型 | 策略 | 关键合同条款 |
|---|---|---|---|
| Cyron 价值成长 1 号 | 股票多头私募 | 中证 800 内基本面选股，20–30 只，月度调仓；研究员入池 → 投委会 → 核心池 | 预警线 0.85、止损线 0.80；单票 ≤ 净值 10%；单一申万一级行业 ≤ 30%；现金 ≥ 2%；禁投池不得买入 |
| Cyron 量化增强 1 号 | 量化指数增强 | 多因子打分 + 风险模型约束优化，对标中证 500，跟踪误差目标 ≤ 6% | 单票偏离基准 ≤ 2%；行业偏离 ≤ 3%；换手与成交量参与率限制 |
| Cyron 成长股权 1 期 | PE / VC 股权基金 | Pre-IPO 成长期投资，投资期 3 年 + 退出期 4 年 | 管理费 2%（投资期按认缴、退出期按未退出成本）；门槛收益 8%；业绩报酬 20%（含追补）；欧式整体分配 |

## 2. 每日账务（二级市场产品）

真实私募的数据起点是**托管行每日估值表**（Excel，固定格式）：

| 科目代码 | 科目名称 | 说明 |
|---|---|---|
| 1002 | 银行存款 | 活期存款 |
| 1021 | 结算备付金 | 证券交易资金 |
| 1102.01 / 1102.02 | 交易性金融资产 - 股票投资（上交所 / 深交所） | 明细到每只股票：数量、单位成本、成本、行情、市值、估值增值、占净值比、停牌标记 |
| 1203 | 应收股利 | 除息日计提、派息日收回 |
| 2206 / 2207 | 应付管理人报酬 / 应付托管费 | 按日计提，按季支付 |
| 2203 | 应付赎回款 | |
| 4001 | 实收基金 | 份额 |
| 合计行 | 资产合计、负债合计、资产净值、单位净值、累计单位净值 | |

账务规则：
- 行情用**不复权收盘价**（与估值表一致）；停牌股沿用最近收盘价并标注。
- 公司行为：**现金分红**在除息日计入应收股利、次一交易日到账；**送股 / 转增**在除权日按比例增加持股数量、成本不变。
- 交易：佣金万 2.5（最低 5 元）、卖出印花税 0.05%（2023-08-28 起）、过户费；T+1 交收简化为当日。
- 费用：管理费年化 1.5%、托管费 0.05%，按日计提（÷365）、季末支付；业绩报酬按高水位法在赎回时提取（模拟中只计提不支付，单列）。
- 申购赎回：按 T 日净值确认份额。

估值表由**模拟器**生成（按真实行情和公司行为逐日记账），再由**解析器**读回——解析器只认估值表格式，接真实托管行文件时不需要改代码。

## 3. 风控与合规

- **合同限额**（YAML 配置在产品上）：预警线 / 止损线、单票、单行业、现金、禁投池；状态：正常 / 预警（达到限额 90%）/ 超限。
- **流动性**：可变现天数 = 持仓数量 ÷（20 日均成交量 × 参与率 20%）；统计 1 日 / 5 日 / 20 日可变现比例。
- **交易前检查**：输入拟下单列表 → 模拟成交后的持仓 → 跑全部合规规则 → 通过 / 拒绝（附原因）。
- **每日风险快照**：VaR / CVaR、回撤、Beta、集中度、风格暴露，入库形成时间序列。
- 所有限额触发写入事件表，需要风控确认处理（留痕）。

## 4. 业绩与归因

- 净值指标：累计 / 年化收益、超额（对沪深300 / 中证500）、最大回撤、波动、夏普、卡玛、胜率、月度收益表。
- **Brinson 归因**（申万一级行业，月度）：配置效应、选股效应、交互效应。
- **风格暴露**：规模、价值、动量、波动、流动性、Beta（截面标准化），监控风格漂移。

## 5. 投研流程（股票多头）

- 股票池：观察池 → 核心池（需投委会批准）；禁投池（合规原因，拦截下单）。
- 研究 Agent 的备忘录作为入池申请材料；投委会决议（批准 / 否决 / 补充材料）、表决记录、生效日期入库。
- 组合调仓只能在核心池内选股。

## 6. 报告

- 每日：风控日报（已有，改为读数据库）。
- 每月：**投资者月报**（PDF）：净值走势、区间收益与回撤、对基准超额、行业分布、前十大持仓（按惯例可选披露）、经理观点。

## 7. 二期：量化

因子库（价值、质量、动量、低波、规模、流动性）→ IC / RankIC、分组回测 → 多因子合成 → 风险模型（行业 + 风格因子截面回归，因子协方差 + 特异风险）→ 约束优化（跟踪误差、行业 / 个股偏离、换手）→ 目标持仓 → 交易前检查 → 模拟成交（成交量参与率、冲击成本）→ 同一套估值表 / 净值 / 合规。

## 8. 三期：PE / VC

项目库（线索 → 立项 → 尽调 → 投决 → 交割 → 投后 → 退出）；尽调 Agent（以真实上市公司招股书作为尽调材料，RAG + 清单）；
IPEV 估值（最近融资价、可比公司倍数、DCF）；基金指标（IRR、TVPI、DPI、RVPI、MOIC）；出资（capital call）与分配；
**收益分配瀑布**（返还实缴 → 8% 门槛收益 → GP 追补 → 80/20）；LP 季报。

## 9. 技术

- 存储：SQLAlchemy 2.0 + SQLite（`data/platform.db`），可切换 Postgres。
- 每日流水线：`veritas fund daily --date`，`veritas fund backfill`；cron / launchd 定时（文档给出配置）。
- Web：新增「产品运营」「风控合规」「业绩归因」「股票池与投委会」页面。
